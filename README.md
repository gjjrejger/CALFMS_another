# Chweya & Associates Law Firm Management System

## CALFMS

CALFMS (Chweya & Associates Law Firm Management System) is a professional
law firm management system and public website designed for Chweya &
Associates.

The project will provide a public-facing website and, in later phases,
an internal management system and client portal.

## Technology Stack

### Frontend
- HTML5
- CSS3
- Vanilla JavaScript

### Backend
- Supabase
- PostgreSQL
- Supabase Authentication
- Supabase Storage

### Development Tools
- Visual Studio Code
- Live Server
- Git
- GitHub
